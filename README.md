# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using transactional purchase data to identify spending patterns, customer segments, product preferences, and subscription trends. The goal is to generate business insights that support data-driven decision making.

## Tech Stack
- Python (Pandas, Data Cleaning, EDA)
- PostgreSQL / MySQL (SQL Analysis)
- Power BI (Dashboard & Visualization)

## Workflow
1. Cleaned and transformed raw customer data using Python.
2. Handled missing values and performed feature engineering.
3. Loaded processed data into SQL database for business analysis.
4. Conducted SQL analysis on revenue, subscriptions, customer segmentation, discounts, and product performance.
5. Built an interactive Power BI dashboard for visualization.

## Key Insights
- Customer spending behavior by age, gender, and subscription status
- Top-performing products and categories
- Revenue analysis and discount impact
- Customer segmentation (New, Returning, Loyal)
- Subscription and repeat purchase trends

## Outcome
Generated actionable business recommendations to improve customer retention, subscription growth, and product strategy.
